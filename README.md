# Pallet Calculator App

Bienvenido/a al proyecto base para una aplicación de cálculo de pallets, creada con Vite + React.

## ¿Qué incluye este proyecto?
- Configuración moderna con Vite y React.
- Listo para importar y procesar archivos Excel (.xlsx).
- Estructura sencilla para que puedas empezar a personalizar tu lógica.

## Requisitos
- Node.js >= 18.x

## Uso rápido

```bash
npm install
npm run dev
```

## Estructura de carpetas principal

- `src/`: Código fuente de React.
- `index.html`: HTML principal.
- `ejemplo.xlsx`: Archivo de ejemplo para pruebas.

## Ejemplo de archivo Excel

Se incluye un archivo `ejemplo.xlsx` como referencia para iniciar el desarrollo de la funcionalidad de importación de datos.
